# Native Home

A clean, minimalist Decky Loader plugin for Steam Deck that adds game logos, Play/Install/Resume quick actions, inline Playtime & HLTB chips, a minimal vertical game list mode, and a theme-adapted Game View with seamless morph transitions.

## Attribution

This plugin is based on the codebase of [Game Glance](https://github.com/michpalm/game-glance) by Michael Palma (`michpalm/game-glance`), licensed under the MIT License.

## Features

- Game logos on the Steam Deck Home screen
- Single Play / Install / Resume button with matching-height Playtime and HLTB chips
- Minimalist vertical title list mode (left/right, optional hidden logo/action panel)
- Built-in theme-adapted Game View with morph transition
- Russian settings UI
